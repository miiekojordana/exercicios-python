# Relação de exercícios - Desenvolvimento em Python
 
 
### Descrição
 
Esse reposítorio destina-se ao armazenamento de exercícios práticos realizados em sala aula, durante o ensino da UC de Desenvolvimento em Python, sob a supervisão e orientação do professor [Leonardo Rocha](leonardossrocha).
 
 
## Exercícios

- exec1.py - Exemplo de uso de biblioteca matemática e data.
- exec2.py - Loop com comando para desligar o motor.
- exec3.py - Cálculo da média de três notas.
